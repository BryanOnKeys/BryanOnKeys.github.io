# Sistema de diseño

Marfil, nogal y latón componen la paleta. La portada une la identidad y los accesos principales con una imagen de ajedrez. Los proyectos alternan superficies claras y oscuras en una cuadrícula que pasa a una columna en pantallas pequeñas.

| Uso                        | Fuente o color |
| -------------------------- | -------------- |
| Títulos y cifras           | Fraunces       |
| Texto y controles          | Inter          |
| Código y nombres de cuenta | JetBrains Mono |
| Papel                      | `#f6eee2`      |
| Nogal                      | `#35261d`      |
| Latón                      | `#915b32`      |

Los tonos del calendario representan los niveles que publica GitHub. Los filtros exponen el estado con `aria-pressed`. Los controles tienen foco visible y las animaciones respetan `prefers-reduced-motion`. Las miniaturas técnicas se identifican como diagramas o composiciones.
